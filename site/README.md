# Сайт «Верни себе себя»

Статический лендинг. Кнопка ведёт в `@teacher_life_bot`.

Если API на другом домене (Render), в `index.html` перед скриптами задайте:

`window.LIFE_API = "https://ВАШ-СЕРВИС.onrender.com";`

Иначе запрос `/api/intent` идёт на тот же хост (удобно, если сайт отдаёт FastAPI).

## Метрика `112323537`

Создайте цели типа **JavaScript-событие** с идентификаторами:

| Цель | Где | Ценность для Директа | Зачем |
| --- | --- | --- | --- |
| `view_offer` | доскролл до оплаты | 100 ₽ | много сигналов, обучение |
| `click_to_telegram` | клик в бота | 500 ₽ | микроконверсия |
| `bot_started` | /start в боте | 2 000 ₽ | дошёл до бота |
| `payment_started` | кнопка оплаты в боте | 15 000 ₽ | сильное намерение |
| `payment_success` | ЮKassa succeeded | 50 000 ₽ | деньги + ecommerce |

В кампании Директа оптимизируйте в итоге на `payment_success`, пока мало оплат — можно временно крутить на `payment_started` или `click_to_telegram`, чтобы алгоритм набрал статистику, затем переключить.

Включите **электронную коммерцию** в счётчике. На успехе уходит purchase на 50 000 ₽.

Включите **Measurement Protocol** и положите токен в `METRIKA_MP_TOKEN` на сервере — иначе цели из бота не доедут.
